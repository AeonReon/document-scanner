Private Document Scanner
========================

What it is:
  Camera/photo-library -> auto-detect document edges -> perspective dewarp ->
  colour / greyscale / B&W filter -> multi-page PDF, JPG, or share.
  100% client-side. No server. No network calls beyond PWA assets.

Stack:
  Vanilla HTML/CSS/JS PWA. No frameworks, no build step.
  Custom canvas pipeline for edge detect, dewarp, filters.
  Custom minimal PDF builder (multi-page image PDFs).
  IndexedDB library for saved scans (stored as JPEG Blobs).

Deploy:
  GitHub: AeonReon/document-scanner
  Vercel: aeonreon team (static, no buildCommand)

Files:
  index.html               main shell + all views
  styles.css               light/bright + gradient outline buttons
  manifest.json            PWA manifest
  sw.js                    service worker (network-first HTML, SWR assets)
  build-stamp.json         bump on each deploy for the version pill + reload banner
  vercel.json              no-cache headers for index/sw/stamp
  js/util.js               tiny helpers
  js/imaging.js            edge detect, perspective dewarp, filters
  js/pdf.js                zero-dep multi-page image PDF builder
  js/db.js                 IndexedDB wrapper
  js/app.js                orchestrator (state, views, capture, crop, filter, export)
  images/                  PWA icons (regenerated by scripts/make_icons.py)
  scripts/make_icons.py    icon generator (Pillow)

Run 2 (2026-05-29) — shipped:
  - Annotations: pen / text / erase with 4 colours (ink/blue/red/highlight)
    Stored normalised, baked onto canvas at export time so PDF + JPG carry the marks.
  - Password-protected PDFs: vanilla RC4-128 standard security handler v2 R3
    Custom MD5 + RC4 in js/pdf.js (no pdf-lib). Empty password = no encryption.
    (Note: RC4-128 is the standard PDF password format readers expect, but it's
    weak crypto by modern standards — useful for casual share, not for secrets.)
  - Library search by name (substring, case-insensitive)
  - Per-card delete button on library

Run 3 (2026-06-05) — shipped:
  - "Auto" magic-colour enhancement (js/imaging.js magicColor): per-channel
    divide-by-blurred-background removes uneven lighting + shadows, auto
    white-balances, lifts contrast. This is the step that makes a phone photo
    read as a SCAN not a snapshot. Now the DEFAULT filter applied on capture
    (page.filter = 'auto'), so every new scan looks cleaned-up immediately.
  - Greyscale + B&W now build on the magic-colour base for cleaner output.
  - Filter chips reordered: Auto (default) / Greyscale / B&W / Original.
  - Edge detection: percentile-based adaptive gradient threshold replaces the
    brittle fraction-of-max threshold, so the document is found + straightened
    far more reliably on real photos (one glare no longer defeats detection).
  - Verified in-browser: synthetic skewed+shadowed page -> detected corners,
    dewarped upright, paper went 0% -> 82.6% clean-white with text intact.
    PDF (plain multi-page + password-locked) build to valid %PDF-1.4.
    MD5/RC4 pass known-answer vectors.

Run 4 (2026-06-05) — UX fixes from first real user test:
  - SCANS NOW AUTO-SAVE. Every scan persists to "My Scans" the moment a photo
    is taken and after every edit (persist() -> saveDocToLibrary). Previously a
    scan only survived if you completed the Export flow, so users who pressed
    Back lost their photos. The Back arrow no longer discards — it just returns
    home, scan kept.
  - Clean human-readable version pill: APP_VERSION = 'v5' (one place to bump),
    replacing the ugly build-stamp digits ("v605004"). Build-stamp is still used
    only to trigger the "new version — tap to reload" banner.
  - Review screen shows a status line ("Auto-cleaned · saved to My Scans · N
    pages") so it's obvious the photo was processed and stored.
  - Delete on a single-page scan now removes it from My Scans (DB.remove).

No API keys. No env vars. Nothing to configure. Zero network calls beyond PWA assets.

Run 5 (2026-06-05) — fix washed-out enhancement + edge feedback:
  - magicColor was dividing by a Gaussian-blurred background; the blur averaged
    the dark TEXT into the paper estimate, so dividing it back out lifted text
    pale = washed out. Fixed by estimating the paper level with a local-MAXIMUM
    (grayscale dilation) before blurring — the max "sees past" sparse dark ink to
    the paper underneath (white top-hat / morphological background). Result: paper
    -> clean white, ink stays dark, colours (logos/stamps) preserved. Verified
    VISUALLY on a synthetic shadowed+skewed colour invoice (screenshot test).
  - Review status line now reports whether edges were auto-detected
    ("cropped to page" vs "no edges found — tap Crop") so auto-crop is visible.
  - v6.

    New 'camera' view in VIEWS + back() handling (closes stream).
  - PDF SIZE OPTION at export: Smaller / Balanced / High. Caps the longest image
    edge (1000/1600/2400) and JPEG quality (0.55/0.72/0.88) per page before
